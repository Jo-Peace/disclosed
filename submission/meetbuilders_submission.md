# Meet the Builders – Google AI tools used

Project: Disclosed · 披露了  
Live site: https://jo-peace.github.io/disclosed/  
Repo: https://github.com/Jo-Peace/disclosed  
Model used: Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`) via the Gemini API (`POST …/v1beta/models/{model}:generateContent`), AI Studio free tier. Briefs are precomputed into static JSON; the browser never holds a key.

## The 3 Google AI usages (all actually implemented)

1. **Gemini API text generation (generateContent, no response schema).** Google Gemini writes a short bilingual (繁體中文 + English) plain-language brief for the top 32 House members by trade count and for the current day's live picks. The prompt is grounded only in structured STOCK Act filing facts (counts, dates, amount ranges, tickers). The site labels these **由 Google Gemini 生成 / Generated by Google Gemini**. Not investment advice.

2. **Gemini structured output / JSON mode.** A second `generateContent` call uses `responseMimeType=application/json` and `responseSchema` to fact-check each brief against the same structured facts. A brief is published only if this check passes and a deterministic guardrail (no invented numbers, required 非投資建議 / “not investment advice” disclaimer) also passes.

3. **Gemini vision (inline image).** Page 1 of three short scanned paper PTRs is rendered to a JPEG and sent as `inline_data`. Gemini transcribes visible rows; code then compares them with our existing parse. This is a second look, not a replacement for the project's full scanned-PDF parse. Results appear on the relevant member pages as **Gemini 視覺複核 / Gemini vision second look**.
